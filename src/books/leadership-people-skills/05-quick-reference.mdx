## Session 1: Motivation

| Theory | In one line |
|---|---|
| **Definition** | Intensity × direction × persistence of effort toward a goal |
| **Maslow** | Physiological → safety → social → esteem → self-actualisation. Famous; weak evidence |
| **Herzberg** | Hygiene factors remove dissatisfaction; motivators create satisfaction. Two separate scales |
| **McClelland** | Achievement (likes 50–50 odds), power, affiliation. Best managers: high power, lower affiliation |
| **ERG (Alderfer)** | Existence, relatedness, growth. No strict order; frustration–regression |
| **Self-determination** | Autonomy, competence, relatedness. Rewards can crowd out intrinsic interest |
| **Goal-setting (Locke)** | Specific + difficult + feedback beats vague or easy. MBO cascades it. Dark side: cheating |
| **Self-efficacy (Bandura)** | Belief you can do this task. Mastery > modelling > persuasion > arousal. Pygmalion effect |
| **Reinforcement** | Behaviour follows consequences. Social learning: attention, retention, reproduction, reinforcement |
| **Expectancy (Vroom)** | Expectancy × instrumentality × valence. A zero anywhere kills motivation |
| **Equity** | Outcome/input ratio against a referent. Justice: distributive, procedural, informational, interpersonal |
| **Engagement** | Physical, cognitive and emotional energy in the work. Dark side: burnout |

| Tool | Remember |
|---|---|
| **Job Characteristics Model** | Skill variety, task identity, task significance → meaning; autonomy → responsibility; feedback → knowledge of results |
| **MPS** | [(SV + TI + TS) ÷ 3] × autonomy × feedback |
| **Redesign** | Rotation (same level), enrichment (more responsibility), relational design (see who you help) |
| **Work arrangements** | Flextime, job sharing, telecommuting |
| **Involvement** | Participative management; representative participation (works councils, board seats) |
| **Pay** | Structure: internal vs external equity; lead, match or lag. Variable: piece rate, merit, bonus, profit sharing, gainsharing, ESOP |
| **Rewards** | Flexible benefits (valence made concrete); recognition (free, powerful, must be fair) |

## Session 2: Groups and teams

| Concept | In one line |
|---|---|
| **Group** | Two or more people, interacting, interdependent, with a shared objective. Formal or informal |
| **Social identity** | The group becomes part of you: ingroup favouritism, social identity threat |
| **Social categorisation** | "They" are all alike; "we" are individuals |
| **Punctuated equilibrium** | Inertia → midpoint transition → renewed inertia → final burst. Temporary groups only |
| **Roles** | Perception, expectations, psychological contract, role conflict |
| **Norms** | Conformity (Asch), Hawthorne effect, four kinds of deviance |
| **Status** | From power, contribution and valued traits. Inequity drives exit |
| **Social loafing** | Less effort when contribution can't be seen; grows with size; weaker in collectivist cultures |
| **Cohesiveness** | Amplifies norms. High cohesion + low performance norms is the worst quadrant |
| **Diversity** | Surface vs deep. Faultlines form where differences line up |
| **Conflict** | Task conflict can help; relationship conflict rarely does |
| **Decisions** | Groupthink and groupshift. Nominal group technique gives the best ideas |
| **Group vs team** | Teams have positive synergy, mutual accountability, complementary skills |
| **Five team types** | Problem-solving, self-managed, cross-functional, virtual, multiteam system |
| **Effectiveness** | Context, composition, process. Trust is a top predictor; optimum size 5–9 |
| **Team players** | Select, train, reward |
| **When to team** | Complexity, common purpose, interdependence |
| **Distributed teams** | Follow the sun; onshore vs offshore; Hofstede; SPLIT: structure, process, language, identity, technology |

## Session 3: Organisation structure

| Concept | In one line |
|---|---|
| **Seven elements** | Specialisation, departmentalisation, chain of command, span of control, centralisation, formalisation, boundary spanning |
| **Three dimensions** | Complexity (horizontal, vertical, spatial differentiation), standardisation, centralisation |
| **Specialisation curve** | Productivity rises, peaks, then falls with boredom and turnover |
| **Departmentalisation** | Functional, product, geographic, process, customer |
| **Span of control** | 4,096 workers: span 4 needs 1,365 managers on 6 levels; span 8 needs 585 on 4 |
| **Eight structures** | Simple, bureaucracy, functional, divisional, matrix, virtual, team, circular |
| **Mechanistic vs organic** | Rules, hierarchy, central decisions vs fluid roles, shared decisions |
| **Contingency factors** | Strategy, size, technology, environment |
| **Strategy and structure** | Cost minimisation → mechanistic; innovation → organic; imitation → mix |
| **Consistency routes** | Formalisation, socialisation, professional socialisation |
| **Effectiveness** | Strategic constituencies: organise around whoever is critical to survival |
| **Exploitation vs exploration** | Do known work better vs do new things. Ambidexterity: both at once |
| **Downsizing** | Redesign the work, or get survivor syndrome |

## Session 4: Change and stress

| Concept | In one line |
|---|---|
| **Core idea** | Manage the loss of the old, not the case for the new |
| **Six forces** | Workforce, technology, economic shocks, competition, social trends, world politics |
| **Individual resistance** | Habit, security, economic fear, fear of the unknown, selective hearing |
| **System resistance** | Structural inertia, limited focus, group inertia, threat to expertise, threat to power |
| **Eight tactics** | With people: communication, participation, support, relationships, fairness. To people: manipulation and cooptation, selection, coercion |
| **Three questions** | Content, process, context |
| **Schein** | Expert mode vs process consultation |
| **Lewin** | Unfreeze, move, refreeze. Force field: release the brake |
| **Kotter** | Urgency, coalition, vision, communicate (unfreeze) · barriers, wins, consolidate (move) · anchor (refreeze) |
| **Action research** | Diagnosis, analysis, feedback, action, evaluation |
| **OD toolkit** | Sensitivity training, survey feedback, process consultation, team building, intergroup development, appreciative inquiry |
| **Change-ready** | Manage paradox, stimulate innovation, learning organisation |
| **Stress** | Demands vs resources. Challenge (keep) vs hindrance (remove). Social support is the best buffer |

## Easy to confuse

| If you see… | Remember… |
|---|---|
| The opposite of satisfaction (Herzberg) | No satisfaction, not dissatisfaction |
| Expectancy theory | The three links multiply, they don't add |
| The strongest source of self-efficacy | Mastery, not modelling |
| MPS | Autonomy and feedback multiply; the other three are averaged |
| Equity | A ratio against a referent, never an absolute amount |
| Punctuated equilibrium | Temporary groups with deadlines only |
| Social loafing | Weaker in collectivist cultures |
| Conscientiousness on teams | Build all-high and all-low teams rather than mixing |
| Matrix structure | Breaks unity of command on purpose |
| Acme vs Omega | "Better" depends on the environment |
| Groupthink's origin | Janis's study of fiascos such as the Bay of Pigs |
| Failed change | Usually skipped unfreezing, not execution |
| Inverted-U stress model | Popular but weakly supported |

## Which case illustrates what

| Case | Use it for |
|---|---|
| **Shivani Carriers** | Existence needs, frustration–regression, goal-setting with expectancy, equity, the damage of changing a reward after it's earned |
| **Greg James at Sun** | Social identity threat, missing norms, status inequity, faultlines, group vs team, virtual-team conditions, shared mental models |
| **The Restaurant** | Structure evolving through four stages; standardisation versus warmth |
| **Acme and Omega** | Mechanistic vs organic, contingency, exploitation vs exploration, ambidexterity |
| **Jess Westerly** | No unfreezing, skipped Kotter 1–4, threat to power, silent resistance, expert mode, ignoring context |

A useful way to analyse any case: **name** the concept, point to the **evidence** in the case, state the **consequence**, then propose the **fix** using the relevant framework.
